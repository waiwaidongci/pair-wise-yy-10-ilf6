# zfl-42 漆线雕返修解锁台

独立静态前端应用，直接打开 `index.html` 即可使用。

业务源码拆分：
- `js/rework.js` 返修判定：返修单的受理、完成、复核、失效与释放资格。
- `js/ledger.js` 占用账本：线材批次占位/释放与阴干位排队重排。
- `js/state.js` 页面状态：localStorage 持久化、动作编排与界面渲染。

已实现闭环：
- 每件作品同时只留一张未结束返修单，重复或并发申请沿用首次受理。
- 登记断线/翘线后只阻止新的领料，已占线材批次维持占位。
- 返修完成须由未登记缺陷者复核；复核前不得释放批次与阴干位。
- 复核通过后进度回退：释放误占批次、重排阴干位、作品退回贴线中。
- 胎体或纹样修正让旧返修单失效。
- 刷新后作品、批次余量与工位顺序一致，支持筛选、排序与 JSON 导出。
